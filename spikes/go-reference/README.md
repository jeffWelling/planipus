# Archived Go reference spike

This is incomplete, uncompiled reference code from the superseded standalone-Go
direction. It sketches domain, deterministic scheduling, immutable preview/apply,
file storage, and HTTP boundaries. It has no executable entry point, UI assets,
tests, or deployment manifests and is not a product foundation.

Do not continue it unless a future ADR reopens the foundation. The active
direction is the clean-room Calendar Sync plan in
`../../docs/ADOPT-OR-BUILD.md`. Import paths, environment variables, metrics,
and build files inside this frozen archive use `planipus-spike` names only to
avoid the rejected historical name. They are not compatibility contracts and
must never be copied into the Planipus product tree.
